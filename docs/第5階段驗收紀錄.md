## 和規格不同、或自己決定的地方（請看一下）

- **匯出用三種通用筆記類型**，不還原你在 Anki 的原本樣板（「0_後醫單字基本型」等）。原本樣板的多個欄位在匯入時已經合併成網站的正面／背面，回到 Anki 是「問答」卡，背面有欄位小標。依 §14-3，搬回 Anki 時是一副新牌。
- **聲音不放離線快取**（規格 §9.5）：第一次播放要連網，之後同一個分頁裡會記住。
- **卡片和題目的每日上限是同一組數字，但分開計算**（例如新卡 20：題目 20、卡片也 20）。
- Anki 裡的「學習中」（剛學、還在分鐘級間隔）匯入時當成到期的複習卡。
- 網站上新增的卡片若用正反或克漏字，一則筆記會拆成多張卡；改克漏字編號時會自動增刪對應的卡。

## 請使用者確認（本機 http://localhost:8787，Safari）

這一階段改了 Worker，所以要**重開**本機網站。匯入會寫進你本機測試版的資料庫（不碰 iCloud 主檔、不碰線上網站）。

1. **重開網站**：原本跑 `scripts/local.sh start` 的視窗按 Ctrl-C，再執行一次 `scripts/local.sh start`，等出現網址。
2. **先試跑（不寫入）**：另開一個終端機視窗，在專案資料夾執行
   `scripts/local.sh pmq anki import "Anki file" --dry-run`
   應該看到：卡片 14,097、牌組 71、有進度 1,109、複習紀錄 2,033、媒體 7,440。預覽在 `reports/anki_import_preview.md`，可以打開看幾張的轉換結果。
3. **正式匯入**：`scripts/local.sh pmq anki import "Anki file"`（約 1 分鐘）
   應該看到：各表的寫入列數，最後沒有錯誤。再跑一次同一行，應該每張表都「寫入 0」。
4. **看卡片**：Safari 開 http://localhost:8787 → 重新整理兩次 → 更多 → 卡片。等右下或側欄顯示「已同步」（第一次約 10 秒）。
   應該看到：03_Physics、05_English 兩個牌組，展開有各章、各單字書；張數和 Anki 相同。
5. **複習一輪**：點「開始複習」→ 看正面 → 按空白鍵或「顯示答案」→ 選評分。
   - 英文卡翻面後會自動唸（聲音要第一次點畫面後才會播，Safari 的規定）；喇叭鈕可以重播。
   - 物理找一張克漏字卡：正面公式裡的空格是框起來的「?」，背面是藍色答案。
   - 物理有圖的卡：圖正常顯示。
6. **自己做卡片**：任一題作答後「⋯」→「做成卡片」→ 儲存；資料庫筆記「編輯區塊」→ 某列點的筆 →「做成卡片」→ 把要挖空的字改成 `{{c1::字}}` → 儲存。
7. **匯出回 Anki（可選）**：`scripts/local.sh pmq anki export ~/Desktop/網站卡片.apkg --deck 3_GRE紅寶書`
   在 Anki「檔案 → 匯入」選這個檔、勾「包含排程資訊」。**建議先匯進一個新的 Anki 設定檔試**，不要直接進你平常用的（§14-3：同一副牌只在一邊複習）。
8. **iPad**（直向）：區網網址開卡片 → 複習幾張；回到 Mac 重新整理，進度一致。

做完第 3 步、確認卡片都在之後，`Anki file/` 就可以刪了（677 MB）。之後要匯其他科目，再從 Anki 匯出放回來即可。
