### 幾個決定

- **不匯入的講義檔**：`05_英文/旋元佑_B1文法_講解.md`（25 章合併成一份，和分章檔重複）、`05_英文/2026_英文_B1_文法.md`（舊版筆記）。寫在 `pmq.toml` 的 `exclude`，要放上去就從那裡拿掉。
- **要讓講義從網站消失**（公開分享前）：`pmq.toml` 把 `ENG = ["05_英文"]` 改回 `ENG = "05_英文"` 再發佈。
- **考卷數只算考試**：講義、教材裡的題目會列在「出現在」，但不算進「幾份考卷」。
- **基本字**：功能字與最基本的字（the、have、good、people…）加上出題用語（passage、paragraph、choose、according…）不進索引，清單在 `vocab.py` 的 `BASIC`。只以大寫出現過的字（人名、地名）也不收。
- **狀態**：常錯＝忘記 2 次以上；已熟＝穩定度 21 天以上。「答錯過」＝卡片忘記過，或答錯的題目裡這個字是選項／答案。
- **常考度**＝考卷數×3＋當答案×4＋當選項×2＋題數（`/vocab` 頁上有寫）。
- 查單字卡先用和螢光小框一樣的「畫面下緣小卡」；3B 的註記卡做好後換過去。

## 給使用者：部署與驗收

Worker 有改（換版的檢查），要跑 `deploy.sh`。

1. 終端機 `cd ~/Projects/postmed-qbank && git checkout stage-8b2`。
2. 裝新的相依：`.venv/bin/pip install -r tools/pmq/requirements.txt`。應該看到 `Successfully installed lemminflect-0.2.3`（或 already satisfied）。
3. `unset CLOUDFLARE_API_TOKEN CLOUDFLARE_ACCOUNT_ID`，再 `scripts/deploy.sh`。應該看到建置成功、`Deployed postmed-qbank`。
4. `bin/pmq publish --subject ENG`。應該看到上傳清單裡有 `c/kb/ENG/Ch01_基本句型-…`…`Ch25…`、`c/vocab/ENG-…`，最後「已換版」。**不要拿掉 `--subject ENG`**（物理、生化主檔還在 iCloud 雲端）。
5. 還沒匯入英文 Anki 牌組的話，現在可以匯：`bin/pmq anki import "Anki file"`（照第 8B-1 驗收紀錄）。沒有卡也能測「新增單字卡」。
6. Safari 打開網站，看到「網站有新版」就按更新。
7. 資料庫 → 英文：應該看到「旋元佑 B1文法」底下 26 份。點 Ch09，選一段字畫螢光，確認正常。
8. 刷題 → 英文 → EN01 字彙與片語 → 開始。在題幹對一個英文字按兩下（iPad 長按選字），選字框最右邊應該有「查單字」。按下去：
   - 有卡 → 畫面下緣出現字義與狀態；按「我不會這個字」，再到「卡片 → 今日複習」應該第一張就是它。
   - 沒卡 → 按「新增單字卡」，Word、例句、出處已經填好，填字義後存檔；題目上那個字出現藍色虛線底線。
9. 作答後往下捲到詳解下方，應該有「這一題的單字」。
10. 更多 → 常考單字：預設「常考而我不會」，點一個字的 ▸ 看它出現在哪些題目。iPad 上請留意進頁到可以捲動大約幾秒。
11. iPad 查一個字 → 等同步 → Mac 打開同一題，應該看得到虛線底線。
