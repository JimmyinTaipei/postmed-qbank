## 和規格不同、或自己決定的地方（請看一下）

- **手寫區放在題目（選項）的正下方**，作答前就能寫；之前的佔位放在詳解底下，那樣物理「做題當空白紙」用不到。
- **「重新作答」怎麼認**：題目以「還沒作答」的樣子出現時就算新的一次。清掉的是「上次作答前畫的」和「在已作答畫面上畫的」；還沒作答就離開、回來接著寫的會留著。模擬考也一樣。
- **紙的大小**：寬固定 1000（顯示時等比縮放到欄寬），高預設 700，每按一次「加長」多 350（上限 4200）。
- **內文的圖上畫的時候，工具列浮在畫面下方**（不在圖旁邊：圖在選項或表格裡時放不下），按「完成」收起。
- **筆的粗細照螢幕上看起來的大小存**：在 iPad 小圖上畫和在檢視器放大後畫，線條在當時的畫面上一樣粗。
- **「圖改過了」的判斷**：記第一次畫的時候那張圖的檔案；之後再畫不覆蓋，提示會一直在，直到清除這張圖的標記。
- **卡片的圖**（Anki 的圖）現在點了也會開檢視器（之前不行），可以放大與標記。
- **列印筆記時不印圖上標記**（規格書寫匯出不另外輸出圖片，列印比照）。
- Apple Pencil 在圖上與手寫區之外的地方左右滑，仍照常換題；只有筆正在畫布上時不換。

## 請使用者確認（本機 http://localhost:8787，Safari）

這一階段改了 Worker，所以要先**重開**本機網站。

1. **重開網站**：原本跑 `scripts/local.sh start` 的視窗按 Ctrl-C，再執行一次 `scripts/local.sh start`，等出現網址。
2. **電腦：手寫區**：Safari 開 http://localhost:8787 → 刷題 → 選物理出一組題 → 題目選項下方點「手寫區」展開 → 用滑鼠在白紙上畫幾筆。
   應該看到：線條跟著滑鼠；按「螢光筆」換顏色畫，底下的線看得見；「復原」「重做」有作用。停 2 秒後左下角變「已同步」。
3. **電腦：物理重新作答清空**：作答這一題 → 再畫一筆 → 回首頁 → 從「更多」或錯題本再打開這一題作答。
   應該看到：手寫區標題是「手寫區」（沒有「有內容」），打開是空白的。
4. **電腦：圖上標記**：找一題有圖的題目 → 點圖 → 檢視器上方按「標記」→ 滑鼠在圖上拖。
   應該看到：畫出線條；放大到 8 倍線條仍銳利、位置不跑；再按一次「標記」後拖曳是移動圖；眼睛按鈕可隱藏標記。關掉檢視器，內文的圖上也看得到剛畫的。
5. **iPad（直向，用區網網址）**：同一題打開手寫區，用 Apple Pencil 寫一段算式。
   請確認：筆跡跟手的延遲可以接受；手掌靠在螢幕上不會畫出東西；手指在紙上拖是捲動頁面。
6. **iPad：直接在內文的圖上畫**：資料庫打開一份有圖的筆記 → 用 Pencil 在小圖上拖。
   應該看到：直接畫出來，下方浮出工具列（按「完成」收起）；Pencil 點一下圖是放大；手指在圖上拖是捲動，不會畫。回到 Mac 重新整理，同一張圖上有剛畫的。
