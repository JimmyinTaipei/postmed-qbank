# 本機版與部署版：一張表看懂

同一套程式、同一份主檔，跑在兩個地方。**兩邊的資料完全分開**，誰也不會自動跟誰同步。

| | 本機版 | 部署版（正式站） |
|---|---|---|
| 網址 | http://localhost:8787（iPad：`start` 印出的 `192.168.x.x:8787`） | https://postmed-qbank.jimmyni312.workers.dev |
| 在哪裡跑 | 你的 Mac（關機、按 Ctrl-C 就沒了） | Cloudflare（隨時都在） |
| 拿來做什麼 | 試新功能、試發佈；**測試用** | 平常讀書、作答、複習 |
| 資料存在哪 | `worker/.wrangler/`（Mac 上） | Cloudflare 的 D1（個人資料）、R2（題庫內容、圖） |
| 登入密碼 | `scripts/local.sh password` 設的（`worker/.dev.vars`） | `scripts/deploy.sh secret password` 設的 |
| 管理金鑰（pmq 用） | `worker/.dev.vars` 自動讀 | Mac 鑰匙圈自動讀 |
| 每個 pmq 指令的寫法 | `scripts/local.sh pmq <指令>` | `bin/pmq <指令>` |
| 換網站程式（Claude 改了 `app/` 或 `worker/`） | 停掉（那個視窗 Ctrl-C）再 `scripts/local.sh start` | `scripts/deploy.sh` |
| 換題庫內容（主檔改了） | `scripts/local.sh publish --subject PHY` | `bin/pmq publish --subject PHY` |

**記法**：指令前面是 `scripts/local.sh` 的，動的就是本機版；`bin/pmq` 直接開頭的，動的就是部署版。

## 兩邊現在各有什麼：`bin/pmq status`

在**另開的終端機視窗**（不是跑著 8787 的那個）：

```sh
cd ~/Projects/postmed-qbank
bin/pmq status
```

它只讀資料，不會改任何東西。會並排列出：

- **網站程式**
  - 「App 版本」是登入頁的檔名。兩邊一樣，大致代表是同一版；但登入頁沒改過的話，看不出差別。
  - 「Worker 有清圖功能」寫「沒有」，表示那一邊還是 11/12 以前的 Worker：部署版要跑 `scripts/deploy.sh`，本機版要重開。
- **題庫內容**：最後一次發佈的時間、每一科的題數、資料庫筆記份數。某一格寫「—」，表示那一邊還沒發佈過那一科。
- **個人資料**：作答紀錄、卡片、手寫、螢光等的筆數。兩邊本來就不一樣，這很正常。
- **儲存空間**：D1 的大小，以及 R2 的圖、Anki 媒體、內容包、備份。

最後一段「兩邊不一樣的」只比網站程式和題庫內容。看到某一科題數不同，就是那一邊還沒用最新的主檔發佈。

本機版沒開時，本機那一欄寫「連不上」，部署版那一欄照樣會列。

## 平常的順序

### A. 主檔改了（新增題目、改詳解、改分類）

1. `bin/pmq check --subject 科目`：等它跑完，看到「擋發佈的錯誤：0 筆」。
2. 想先在本機看：`scripts/local.sh publish --subject 科目`。8787 要開著。
3. 確定沒問題：`bin/pmq publish --subject 科目`，這一步發佈到部署版。
4. `bin/pmq status`：兩邊的題數應該一樣。

科目代碼：`PHY` 物理、`BCH` 生化、`ENG` 英文、`CHE` 化學、`BIO` 生物。

### B. Claude 改了網站程式（`app/`、`worker/`）

1. **本機版**：跑著 8787 的視窗按 Ctrl-C，再 `scripts/local.sh start`。
2. 用 Safari 開 localhost:8787 試試看。
3. **部署版**：
   ```sh
   unset CLOUDFLARE_API_TOKEN CLOUDFLARE_ACCOUNT_ID
   scripts/deploy.sh
   ```
4. `bin/pmq status`：「Worker 有清圖功能」兩邊都應寫「有」。之後再有類似的新功能，Claude 會在驗收紀錄裡寫要看哪一列。

### C. 清掉雲端沒用到的圖（`pmq prune`）

- 部署版：先 `bin/pmq prune`（只列出來），數字合理再 `bin/pmq prune --yes`。
- 本機版：`scripts/local.sh pmq prune`，再 `scripts/local.sh pmq prune --yes`。

## 注意

- **跑著 8787 的視窗不能打字**：`t` 會開對外通道，`q`／`x` 會關掉網站。其他指令一律另開視窗。
- **主檔沒下載完，`check`／`publish` 會看起來像卡住**：iCloud 只放在雲端的檔，讀到時要先下載。先在 Finder 對那一科的資料夾按右鍵「立即下載」，等雲朵圖示消失再跑。要看還有幾個檔沒下載：
  ```sh
  find ~/"Library/Mobile Documents/com~apple~CloudDocs/後醫/08_考古題與模擬考/82_考題整理/01_題庫製作/物理" -flags +dataless -type f | wc -l
  ```
  顯示 0 才算下載完。
- 本機版的作答、卡片不會跑到部署版。想把本機的卡片搬過去，要另外處理，請先問 Claude。

細節：本機版看 [`本機測試步驟.md`](本機測試步驟.md)，部署版看 [`部署步驟.md`](部署步驟.md)。
