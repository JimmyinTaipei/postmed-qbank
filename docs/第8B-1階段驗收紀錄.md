決定與注意：

- **migration 編號**：規劃原本是「0002 克漏字（5B）、0003 單字（8B-1）」。8B-1 先做，所以單字這份是 `0002_vocab.sql`，**5B 的 `cloze_mark` 改用 0003**（已改 `03_分階段計畫.md` 那一行）。
- 樣板照 §13.2：不搬背景圖、毛玻璃、陰影；顏色用網站的代碼。正面的喇叭鈕放在單字旁邊；**自動播放**和 Anki 一樣只在翻面時（Anki 的正面樣板沒有放聲音）。
- 例句的中文遮罩用和你 Anki 樣板相同的字元範圍（中文、全形標點）；公式、圖、聲音語法裡面不動。加了「顯示全部中文」給鍵盤和一次看完用。
- 背面「辨析」那塊的小標顯示「辨析與易混淆」（規格書的寫法）；`back_md` 裡（搜尋、TSV）仍是 pmq.toml 的「辨析」。
- 編輯表單在 3B 之前是純文字框；3B 做完換成 `RichEditor`。「圖與聲音」那格是 `[sound:m/…]` 語法，從 Anki 搬來的卡不用動它。
- 舊版 App（還沒重新整理的分頁）編輯單字卡時會把 `fields` 清掉、退回一般卡的顯示；重新整理一次就是新版。
- 匯入清單沒有「5_廣讀與學科單字」（9 張）與「9_字根字首」（247 張），沿用第 5 階段你的決定。要加就在 `pmq.toml` 的 `[anki] import` 加一行。
- §13.3 的 typography／accessibility／break-ui 檢查只做了深色、寬度與鍵盤（「顯示全部中文」）；沒有另外跑 Skill。

## 你要做的測試（Mac Safari＋iPad）

你的 8787 目前 0 張卡，英文和物理都還沒匯入，所以直接照下面做就好（不用 `--update`）。

1. **重開 8787**（這次改了 Worker 與資料表）：原本跑 `scripts/local.sh start` 的視窗按 Ctrl-C，再執行一次 `scripts/local.sh start`。
   應該看到：「本機資料表就緒」（新的 `0002_vocab.sql` 會在這一步自動套用）、然後出現網址。關不掉的話看 `docs/本機測試步驟.md` 最後一節。
2. **試跑（不寫入）**：另開一個終端機視窗，在專案資料夾執行
   `scripts/local.sh pmq anki import "Anki file" --dry-run`
   應該看到：`05_English.apkg：13,621 張`、`牌組 71、卡片 14,097、有進度 1,109、複習紀錄 2,033、媒體 7,440 個`。`reports/anki_import_preview.md` 的「0_後醫單字基本型」那一節，每張多一段「欄位」。
3. **正式匯入**：`scripts/local.sh pmq anki import "Anki file"`（約 1–2 分鐘）。
   應該看到：最後一行「完成」，沒有「被拒」。再跑一次同一行，card／srs_state／review_log 都是「寫入 0」。
4. **看一張單字卡**：Safari 開 http://localhost:8787 → 重新整理兩次 → 更多 → 卡片 → 05_English → 1_高中核心6000單 → level 5 → 搜尋 `debut` → 點它。
   應該看到：標題「單字卡」；「正面」那塊只有大字 debut 和喇叭、「提示／例句」「標籤」兩顆鈕；「背面」那塊是 debut＋n.、分隔線、深藍大字「初次登場；開端」，下面依序例句、衍生字、辨析與易混淆（左邊紅線）、反義字、字根字首，最後是標籤。
5. **正面的按鈕**：在「正面」那塊按「提示／例句」。
   應該看到：橘色框裡英文例句照常、中文是灰色色塊；點一個色塊那一句中文就出現，再點又遮回去；按「顯示全部中文」全部出現。按「標籤」出現 3 個標籤。
6. **聲音**：按單字旁的喇叭。應該聽到 debut 的發音（第一次可能要先點一下畫面，Safari 的規定）。
7. **複習一輪**：回到 05_English → 「複習這個牌組」→ 正面只有單字 → 空白鍵翻面（應該自動唸一次）→ 按 1–4 評分 → 下一張的提示與標籤是收起來的。
8. **編輯**：任一張單字卡 →「⋯」→ 編輯。應該看到 11 格（單字、詞性、字義、例句…出處）＋標籤。改一格存檔 → 卡片頁馬上是新的內容。
9. **新增單字卡**：卡片 → 新增卡片 → 種類選「單字」→ 填單字與字義 → 新增 → 到那個牌組搜尋得到。
10. **iPad**（直向、再轉橫向）：用區網網址打開同一張卡與複習畫面。應該看到：版面沒有被撐破、沒有左右捲動；在 iPad 改的卡，回 Mac 重新整理後一樣。
11. **匯出回 Anki（可選）**：`scripts/local.sh pmq anki export ~/Desktop/英文單字.apkg --deck 05_English`
    建議先匯進一個**新的 Anki 設定檔**試（檔案 → 切換設定檔 → 新增），匯入時勾「包含排程資訊」。應該看到：筆記類型是「0_後醫單字基本型」、卡片外觀和你原本的一樣（背景圖不會帶過去，因為網站沒有那張圖）。

確認第 3–4 步沒問題後，英文單字就算搬好了；`Anki file/` 之後要不要刪由你決定。
