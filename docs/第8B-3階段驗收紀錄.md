### 批次的樣子


### 幾個決定

- **常見字不排**：你的英文牌組沒有 effect、argue、two 這種字（不是漏了，是本來就會），不擋的話第一批 100 個字幾乎都是這種。用 wordfreq 詞頻（Apache-2.0）Zipf 4.3 以上的字當常見字，做成固定的字表，**不增加相依套件**。要連常見字也排：`--include-common`。`/vocab` 與單字索引不受影響。
- **例句只給真的句子**：文章的硬換行接回同一句；克漏字的空格代入那一小題的正確答案（`The whole village was inundated by the tsunami.`）；挑錯題的句子本身有錯，不給；作答說明（Which of the following…、in paragraph 2…）排在最後。
- **Flash 只填 9 格**：Image 留空，Source 由 import 填（它選的那句的「來源｜ID」）；例句裡的那個字由 import 加粗（和網站「新增單字卡」一樣）。這樣 Flash 少一個出錯的地方。
- **詞性清單**照你 Anki 13,877 張卡實際用的寫法：`n. v. adj. adv. phr. prep. pron. conj. aux. det. interj.`，多個用全形「；」接（例如 `n.；v.`）。你的卡裡也有 `n., v.`、`n. v.` 這種寫法（約 50 張），新卡統一成「；」。
- **簡體字檢查不用套件**：Big5（cp950）編不出、GB2312 編得出的字＝簡體字。「著、裡、後、才、台」這類繁簡共用的字不會誤判；「着」會被擋（台灣寫「著」）。
- **已經排過的字不會再排**：todo 會跳過之前任何 V 批次裡的字。要重排就刪掉那個批次資料夾。
- **同一個檔匯入兩次不重複**：卡片 ID 由字決定（`ai-<雜湊>`）；網站上已經有這個字的卡（不論 AI 還是你自己建的）就略過並列出來。
- **義項**：做了 todo 與 check，**import 沒做**——網站還沒有顯示「這一題用第幾個意思」的地方。而且你的字義欄多半是同義詞並列（「強調；著重」），不是真的不同義項，建議**先不要跑**這個任務。

## 給使用者：部署與第一批

App 有改（AI 標示），Worker 沒改。

1. 終端機：`cd ~/Projects/postmed-qbank && git checkout stage-8b3`。
2. `unset CLOUDFLARE_API_TOKEN CLOUDFLARE_ACCOUNT_ID`，再 `scripts/deploy.sh`。應該看到建置成功、`Deployed postmed-qbank`。
3. 產生第一批：`bin/pmq vocab todo`。應該看到「批次 V001：…/90_工作暫存/英文單字/V001」與「100 個字」。（網站上要先匯入過英文 Anki 牌組；沒匯入的話它會把你已經有卡的字也排進來。）
4. 打開 Antigravity，叫 Flash：「讀 `<V001 資料夾>/任務單.md`，照做」。
5. Flash 說做完後：`bin/pmq vocab check "<V001 資料夾>/輸出.json"`。
   - 看到「✗ 沒過」→ 打開同一個資料夾的「檢查結果.md」，整份貼給 Flash，請它重新輸出，回到第 5 步。
   - 看到「✓ 通過」→ 下一步。
6. 先抽看幾筆：打開 `輸出.json`，看字義、例句翻譯、字根是不是你要的樣子。
7. `bin/pmq vocab import "<V001 資料夾>/輸出.json"`。應該看到「新卡 100 張」。
8. Safari 打開網站 → 卡片 → `05_English › 考古題單字`：應該有 100 張新卡、標籤 AI。翻到背面，字義、例句等格子旁邊有橘色小字「AI」；卡片資訊有「AI 產生（批次 V001）」。
9. 編輯其中一張、改字義後存檔：字義旁的「AI」消失，其他格還在。
10. 把 Flash 跑偏的地方（`check` 沒擋到、但你不滿意的）告訴我，補進任務單與 `check`。
