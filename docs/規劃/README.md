## 結論摘要

1. **以誰為準**：題目、詳解、圖、筆記以 Mac 上現有的檔案為準（原位不動，加 git 歷史）；作答、錯題、複習、個人筆記、螢光、手寫以雲端資料庫為準。在網站上改的內容先進「修訂佇列」、畫面立刻生效，再由 Mac 上一個指令寫回主檔。
2. **平台**：全部放 Cloudflare（一個 Worker＋D1＋R2），與護理站同帳號，預期新增月費 0。不用 Supabase、Pages、Cloudflare Access；用 Worker 內建的單一密碼。部署由使用者本人執行。
3. **離線**：做。
4. **刷題模式**：自訂篩選、原卷模擬、錯題重練、今日複習（FSRS）、弱點章節、續做；另有各科通用的考題分析。
5. **公式與圖**：KaTeX＋mhchem；SVG 向量顯示，可放大 8 倍，深色模式放白色紙卡。
6. **iPad 與電腦功能完全一致**，只有版面與按鈕大小不同。
7. **外觀**：簡潔、單一藍色主題，色碼取自護理國考測驗網站；每階段用 Skill 檢查。
8. **Apple Pencil 手寫**：第 6 階段；物理每次重做清空，其他科保留。
9. **SVG 與 LaTeX 編輯器**：第 7 階段整合進新站，SVG 核心檔仍只有 `scripts/svg_editor/` 一份。
10. **備份**：每晚自動備份到 R2；隨時可下載整包；可灌回全新的資料庫。
11. **護理國考網站**：新專案只碰名稱為 `postmed-qbank` 的三個資源，不動任何網域與帳號設定。
