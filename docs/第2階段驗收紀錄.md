## 和規格不同、或自己決定的地方（請看一下）

| 項目 | 做法 | 理由 |
|---|---|---|
| 不做 FSRS 的短期學習步驟（「1 分鐘、10 分鐘後再出一次」） | 答錯 → 隔天到期 | `srs_state` 沒有存學習步驟的欄位；題庫題目在 10 分鐘內重出意義不大 |
| 什麼時候排程 | 作答「封存」時（離開那一題），不是按下選項的當下 | 那時「猜的／普通／很確定」才定案，評分才對 |
| 已在排程裡的題目，在刷題、錯題重練、原卷裡作答也算一次複習 | 寫 `review_log`、更新排程 | 和 Anki 不同（Anki 只有複習時才算）；但同一題真的又做了一次，記憶狀態本來就變了 |
| 每日上限只算「今日複習」模式裡做的 | 其他模式的作答不佔上限 | 否則刷一般題目會把當天的複習額度用掉 |
| 「Easy」的用時門檻 | 同題型最近 400 筆答對的用時中位數的一半；資料少於 5 筆時不給 Easy | 規格只說「該題型中位數」，沒說取多少筆 |
| 模擬考的時間選項 | 不計時／60／80／100／120 分，預設 80 | 規格沒寫；之後可改成依各校實際時間 |
| 模擬考裡的非選擇題 | 不計分，交卷後從結果頁點進去自己對 | 交卷前不能顯示答案，而自評題要看答案才能評 |
| 原卷方格的分類 | 「後醫」與「其他考試」（轉學考、醫事國考）兩組；同校同年的多份卷合併成一格 | 方格只有學校 × 年份兩個軸 |
| 考題分析的兩個層級 | 「大單元」（物理的分組、生化的書）與「章」 | 各科通用，沒有寫死物理的分組 |
| 弱點章節的門檻 | 至少做過 10 題（樣板寫 20） | 剛開始用時也看得到東西；之後可調 |
| 「做錯過」條件 | 包含已經離開錯題本的題目 | 「現在還在錯題本的」用錯題本頁的「錯題重練」 |

## 請使用者確認（本機 http://localhost:8787 或 iPad）

1. 刷 10 題故意錯幾題 → 錯題本有它們；今日複習頁「未來兩週到期」明天那欄有數字。
2. 答錯後按「粗心錯，不追蹤」→ 錯題本沒有它；單題頁 ⋯ →「恢復追蹤」→ 回到錯題本。
3. 單題頁 ⋯ →「加入複習」→ 今日複習多 1 題新題。
4. 更多 → 原卷 → 點一格 → 開始模擬考 → 答幾題（看不到對錯）→ 離開再從今日頁續考，時間沒歸零 → 交卷看得分。
5. 更多 → 題庫瀏覽 → 搜「高醫 115」、一個中文詞、一個英文詞，iPad 上 1 秒內出現。
6. 兩台裝置：iPad 與 Mac 各做今日複習裡的同一題，同步後兩邊的到期日一致。
