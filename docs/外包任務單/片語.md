# 任務單 {{batch}}：找出一份考卷裡的片語

（這份任務單由 `pmq vocab todo --kind phrases` 產生。範本在專案的 `docs/外包任務單/片語.md`。）

## 你要做的事

讀 {{paper}} 的 **{{n}} 段文字**（每一題，以及閱讀測驗、克漏字的文章），找出裡面值得背的 **英文片語與慣用語**（例如 `give rise to`、`in terms of`、`be prone to`、`take ... for granted`），全部放進 **一個** JSON 檔。

- 工作資料夾：`{{dir}}`
- 讀：`輸入.json`（同一個資料夾）
- 寫：`輸出.json`（同一個資料夾）——**這是你唯一可以建立的檔案**

## 絕對不可以

1. 不可以修改、移動、刪除任何現有的檔案（包括 `輸入.json`、這份任務單）。
2. 不可以在工作資料夾以外建立任何檔案，也不可以在資料夾裡建立 `輸出.json` 以外的檔案。
3. 不可以增加、刪除、改寫題目的 `id`。輸入有幾段，輸出就剛好幾筆，順序照輸入；沒有片語的段落也要寫一筆，`phrases` 寫 `[]`。
4. 不可以翻譯、解釋、加中文。這個任務只要英文片語。
5. 不要收：單一個字、專有名詞、一般的「形容詞＋名詞」組合（`important role`）、整個句子。

## 輸入.json 的格式

```json
{"kind": "phrases", "batch": "{{batch}}", "paper": "ENG-CMU-113", "label": "中國 113",
 "items": [
   {"id": "ENG-000949", "text": "The whole village was _____ by the tsunami. (A) infatuated ..."},
   {"id": "g:ENG-000990", "text": "（閱讀測驗的文章全文）"}
 ]}
```

`id` 以 `g:` 開頭的是一篇文章（題組），其他是一題。

## 輸出.json 的格式

整個檔案就是一個 JSON 陣列，**不要用 ``` 包起來，前後不要加任何說明文字**：

```json
[
  {"id": "ENG-000949", "phrases": []},
  {"id": "g:ENG-000990", "phrases": [
    {"phrase": "give rise to", "text": "gave rise to"},
    {"phrase": "in terms of", "text": "in terms of"}
  ]}
]
```

| 欄位 | 規定 |
|---|---|
| `id` | 照輸入的 `id` 原樣抄。 |
| `phrase` | 片語的 **原形**，2～6 個英文字，小寫（專有的大小寫除外）。動詞片語用原形（`give rise to`，不是 `gave rise to`）；中間可以代換的部分寫 `sb`、`sth`、`one's`（`take sth for granted`）。 |
| `text` | 這個片語在 `text` 裡實際出現的樣子，**一字不差地從輸入複製**（含大小寫、時態、中間的字）。程式會用它在題目裡找位置，找不到就不算。 |

同一段裡同一個片語只寫一次。

## 做完之後

1. 自己再檢查一次：筆數等於 {{n}}、每個 `text` 都真的出現在那一段裡。
2. 告訴使用者「{{batch}} 做完了」。使用者會跑 `bin/pmq vocab check` 檢查；沒過的話，會把「檢查結果.md」貼回來，請照清單修正，**重新輸出整個 `輸出.json`**。
