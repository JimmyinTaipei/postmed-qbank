# 任務單 {{batch}}：一字多義，考古題用的是哪個意思

（這份任務單由 `pmq vocab todo --kind senses` 產生。範本在專案的 `docs/外包任務單/義項.md`。）

## 你要做的事

`輸入.json` 有 **{{n}} 個字**，每個字有幾個中文字義（已編號），以及它在考古題裡出現的句子（共 **{{places}} 個位置**）。判斷 **每個位置** 用的是第幾個字義，全部放進 **一個** JSON 檔。

- 工作資料夾：`{{dir}}`
- 讀：`輸入.json`（同一個資料夾）
- 寫：`輸出.json`（同一個資料夾）——**這是你唯一可以建立的檔案**

## 絕對不可以

1. 不可以修改、移動、刪除任何現有的檔案（包括 `輸入.json`、這份任務單）。
2. 不可以在工作資料夾以外建立任何檔案，也不可以在資料夾裡建立 `輸出.json` 以外的檔案。
3. 不可以增加、刪除、改寫字或位置。輸入有幾個位置，輸出就剛好幾筆。
4. 不可以新增字義、改寫字義。只能從清單選一個編號；都不太對時選最接近的。

## 輸入.json 的格式

```json
{"kind": "senses", "batch": "{{batch}}",
 "words": [
   {"word": "address", "senses": ["1. 地址", "2. 演說", "3. 處理；應付"],
    "places": [{"at": "ENG-000204s", "sentence": "The government must address the problem of rising costs."}]}
 ]}
```

## 輸出.json 的格式

整個檔案就是一個 JSON 陣列，**不要用 ``` 包起來，前後不要加任何說明文字**。每個位置一筆，剛好三個欄位：

```json
[
  {"word": "address", "at": "ENG-000204s", "sense": 3}
]
```

| 欄位 | 規定 |
|---|---|
| `word` | 照輸入原樣抄。 |
| `at` | 照輸入原樣抄。 |
| `sense` | 字義的編號（整數，不加引號）。 |

## 做完之後

1. 自己再檢查一次：筆數等於 {{places}}。
2. 告訴使用者「{{batch}} 做完了」。使用者會跑 `bin/pmq vocab check` 檢查；沒過的話，會把「檢查結果.md」貼回來，請照清單修正，**重新輸出整個 `輸出.json`**。
