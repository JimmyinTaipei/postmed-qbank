# 任務單 {{batch}}：替考古題單字填單字卡欄位

（這份任務單由 `pmq vocab todo` 產生。範本在專案的 `docs/外包任務單/單字欄位.md`。）

## 你要做的事

替 `輸入.json` 裡的 **{{n}} 個英文字**，每個字寫一筆單字卡內容，全部放進 **一個** JSON 檔。

- 工作資料夾：`{{dir}}`
- 讀：`輸入.json`（同一個資料夾）
- 寫：`輸出.json`（同一個資料夾）——**這是你唯一可以建立的檔案**

## 絕對不可以

1. 不可以修改、移動、刪除任何現有的檔案（包括 `輸入.json`、這份任務單）。
2. 不可以在工作資料夾以外建立任何檔案，也不可以在資料夾裡建立 `輸出.json` 以外的檔案（不要草稿、備份、說明檔）。
3. 不可以增加、刪除、改拼法、改大小寫清單上的字。清單上有幾個字，輸出就剛好幾筆，順序照清單。
4. 例句（Sentence）**只能用輸入裡給的原句**，一字不差地複製；不可以自己造句、改寫、刪減、補標點，也不可以從字典找別的例句。輸入沒有給原句（`sentences` 是空的）的字，Sentence 寫 `""`。
5. 所有中文一律用 **繁體中文（台灣用字）**，不可以有簡體字。
6. 不可以用 HTML 標籤、Markdown 粗體 `**`、程式碼框。

## 輸入.json 的格式

```json
{
  "kind": "fields", "batch": "{{batch}}",
  "words": [
    {"word": "inundate", "forms": ["inundated"], "papers": 3, "questions": 4,
     "sentences": [{"text": "The whole village was inundated by the tsunami.", "source": "中國 113 01｜ENG-000949"}]}
  ]
}
```

- `word`：要做卡的字（原形）。片語批次時是一個片語。
- `forms`：這個字在考古題裡出現過的變化形，參考用。
- `sentences`：考古題裡含這個字的原句（最多 3 句）。`source` 不用抄進輸出。

## 輸出.json 的格式

整個檔案就是一個 JSON 陣列，**不要用 ``` 包起來，前後不要加任何說明文字**。每個字一筆，每筆剛好下面 9 個欄位（沒有內容的欄位寫 `""`，不可以省略，也不可以多加欄位；`Image`、`Source` 不要寫）：

```json
[
  {
    "Word": "inundate",
    "Part of Speech": "v.",
    "Meaning and Definition": "淹沒；使應接不暇",
    "Sentence": "The whole village was inundated by the tsunami.\n整個村莊被海嘯淹沒了。",
    "Memo & Confusable": "【辨別】inundate 淹沒 vs. infatuate 使迷戀",
    "Derivative": "inundation n. 洪水；氾濫",
    "Synonyms": "flood v. 淹沒\nswamp v. 使應接不暇",
    "Antonyms": "",
    "Prefix & Roots": "【語源】\nin（進入）＋ und（波浪，源自拉丁語 unda）＋ ate（動詞字尾）→ 波浪湧進來 → 淹沒\n\n【同根詞】\nundulate v. 起伏；波動"
  }
]
```

各欄位的規定：

| 欄位 | 規定 |
|---|---|
| `Word` | 照清單上的 `word` 原樣抄（拼法、大小寫都不能改）。 |
| `Part of Speech` | 只能用這幾個：{{pos}}。兩個以上用全形分號「；」接、不加空白，例如 `n.；v.`。片語寫 `phr.`。**不能空白。** |
| `Meaning and Definition` | 繁體中文字義，幾個意思用全形分號「；」分開，常用的放前面，最多 4 個。以後醫英文考試會考的意思為主。**不能空白。** |
| `Sentence` | 從 `sentences` 選 1～2 句，**一字不差**地複製。每句下一行可以加這句的繁體中文翻譯。句子之間、句子與翻譯之間用 `\n` 換行。英文與中文不能寫在同一行。沒有給原句就寫 `""`。 |
| `Memo & Confusable` | 容易混淆的字（拼法或意思相近）：`【辨別】A 中文 vs. B 中文`。沒有就 `""`。 |
| `Derivative` | 衍生字，一行一個：`字 詞性 中文`。沒有就 `""`。 |
| `Synonyms` | 同義字，一行一個：`字 詞性 中文`，最多 4 個。沒有就 `""`。 |
| `Antonyms` | 反義字，同上。沒有就 `""`。 |
| `Prefix & Roots` | `【語源】` 一行說明字首字根的拆法，接著空一行 `【同根詞】` 一行一個。不確定的語源寧可寫 `""`，不要編。 |

## 做完之後

1. 自己再檢查一次：筆數等於 {{n}}、每筆 9 個欄位、例句是原句、沒有簡體字。
2. 告訴使用者「{{batch}} 做完了」。使用者會跑 `bin/pmq vocab check` 檢查；沒過的話，會把「檢查結果.md」貼回來，請照清單修正，**重新輸出整個 `輸出.json`**（同樣只能動這一個檔）。
